# Atelier IA citoyen LN-IA

Public : citoyens, parents, enseignants et professionnels débutants. Écrire en français clair et expliquer le vocabulaire.

Référence initiale : guide-source-pedagogique-IA-LN-IA.docx, version 1.0 du 7 octobre 2026. Préserver les fichiers originaux et les deux consignes. Les changements sont entretenus dans content/ ; consigner les écarts avec le guide dans docs/journal-validation.md.

Méthode : besoin, cadrage, prompt, production, contrôle, correction, documentation et preuve. Toute activité comporte objectif, durée, consigne, résultat attendu, corrigé expliqué, critère de réussite et référence au guide.

Toute affirmation évolutive nécessite une source officielle et une date. Ne pas confondre catalogue API et accès dans une application. Conserver « non confirmé » si la preuve manque. Aucune citation ou donnée inventée.

Site Vite statique, sans clé API, sans compte et sans envoi de données. Contenus séparés de src/. Téléphone, clavier, ordinateur et impression doivent rester utilisables. Une connexion est nécessaire pour consulter les liens externes ; prévoir des preuves embarquées.

Contrôles : npm run validate ; examiner activité, navigation directe par fragment, exports, ressources, impression et téléphone. Documenter les limites réelles. Ne pas déclarer une validation humaine effectuée à partir d’un build.

Première publication après examen et validation explicite du responsable. Aucun push, envoi ou déploiement sans autorisation. Déploiement manuel depuis main. Préserver les originaux ; vérifier leur empreinte avec scripts/check-content.mjs.
