# Contrôle de publication

Avant publication : npm ci puis npm run validate. Relire activités, faits et sources. Confirmer les droits de diffusion du guide et des images. Tester clavier, téléphone, impression, téléchargements, exports et carnet sur appareil partagé. Corriger les erreurs majeures. Consigner responsable, date, commit et décision dans journal-validation.md.

La compilation ne valide pas les faits. La première publication exige une validation humaine explicite. Le déploiement reste manuel sur main avec VALIDE ; aucune publication n’est lancée depuis le travail local.

Après publication : noter URL, commit et version ; essayer l’activité principale, ouvrir directement #exercices, télécharger guide et kit, tester sur téléphone et recharger pour vérifier la version.

En cas de défaut : préparer git revert du commit fautif, contrôler et redéployer après relecture. Ne pas effacer l’historique. Archiver date, cause et correction.
